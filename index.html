    03 //
    policy → pipelines
    

  
    
    
    
      
    hackathon · production-track · gcp + vertex ai
    
      
    natural language controls
    → enforced guardrails + drift fix.
    
      
    
        A multi-agent LangGraph platform that takes a plain-English policy like
        “All GCS buckets must have cost_center, environment and team labels”
        and turns it into compiled rules, live drift detection, risk-scored
        gcloud remediation plans, human-in-the-loop approvals, and audit-ready
        evidence — running against real GCP (Gemini 2.5 Pro on Vertex AI) or fully
        offline in mock mode for CI.

    Generates ordered, reversible gcloud commands per violation, with rollback hints and blast-radius estimates.

    Risk Assessor
    Guardrails first (BLOCKED / HIGH_RISK), then LLM rubric scoring (0–10). Auto-approve below 4, human review above.

    Runs approved commands via gcloud, re-queries the resource for post-state proof, refuses unapproved plans.

    LangGraph state machine
    Conditional routers short-circuit on rejection or cloud-error; per-stage timings let the UI render a Gantt of agent execution.
    
    
    Guardrails & risk engine
    BLOCKED patterns force score=10. HIGH_RISK patterns boost LLM score by +6 to push past auto-approve. Naming-convention violations always require human review.
    
    
    Policy template library
    7+ YAML controls for GCS, Compute, IAM, Cloud SQL, VPC. Loadable via /api/templates and applyable in one click.
    
    
    Provider pluggable
    Mock / LiteLLM / Vertex AI for LLM. Mock / GCP for cloud. AWS & Azure scaffolded next.
    
    
    Audit-ready
    EvidencePack bundles: policy + finding + plan + before/after state + execution log. Persisted to Firestore in prod.
    
    
    Stack
    LangGraph · LangChain · FastAPI · Pydantic v2 · React + Vite · APScheduler · Cloud Build · Firestore · Podman.
