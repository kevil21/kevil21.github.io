    03 //
    policy → pipelines
    

  
    
    
    
      
    hackathon · production-track · gcp + vertex ai
    
      
    natural language controls
    → enforced guardrails + drift fix.
    
      
    
        A multi-agent LangGraph platform that takes a plain-English policy like
        “All GCS buckets must have cost_center, environment and team labels”
        and turns it into compiled rules, live drift detection, risk-scored
        gcloud remediation plans, human-in-the-loop approvals, and audit-ready
        evidence — running against real GCP (Gemini 2.5 Pro on Vertex AI) or fully
        offline in mock mode for CI.

    Guardrails & risk engine
    BLOCKED patterns force score=10. HIGH_RISK patterns boost LLM score by +6 to push past auto-approve.
    
    
    Policy template library
    7+ YAML controls for GCS, Compute, IAM, Cloud SQL, VPC. Loadable via /api/templates.
    
    
    Provider pluggable
