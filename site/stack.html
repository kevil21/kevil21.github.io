everything I touch.

A complete inventory of the languages, frameworks, services and tools that power Kevil.OS, A360 and Policy → Pipelines.

  • HTML / CSS / vanilla JS (no build)
  • GSAP 3.12 + ScrollTrigger
  • Lenis smooth scroll
  • Web Audio API (custom synth)
  • Inline SVG + canvas FX
  • Google Fonts: JetBrains Mono, Space Grotesk, Syncopate, Instrument Serif

  • Kyndryl Shidoka design system (Lit web components)
